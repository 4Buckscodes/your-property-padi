# User Stories

## Story 1

As a first-time buyer,

I want to understand property documents,

so that I don't get scammed.

---

## Story 2

As an investor,

I want to compare locations,

so that I can maximise returns.

---

## Story 3

As someone in the diaspora,

I want trustworthy guidance,

so I can invest remotely.

---

## Story 4

As a seller,

I want to know how to prepare my property,

so I can sell faster.

---

## Story 5

As a landlord,

I want to understand property management,

so I can reduce problems.

---

## Story 6

As a student,

I want to learn real estate,

so I can become knowledgeable.
